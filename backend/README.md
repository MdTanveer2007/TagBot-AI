# TagBot AI Backend

This folder will contain the core backend logic of TagBot AI.

## Planned Responsibilities

- Connect to the AI model
- Receive and process user messages
- Manage conversation flow
- Connect the memory system
- Retrieve information from the Knowledge Vault
- Call tools and external APIs
- Handle authentication and security
- Provide responses to the future web interface

## Initial Technology Direction

- Python
- FastAPI
- SQLite
- Gemini API
- Markdown-based Knowledge Vault

The backend will be built gradually, starting with a simple local chat API and adding memory, tools, and agents only when needed.
